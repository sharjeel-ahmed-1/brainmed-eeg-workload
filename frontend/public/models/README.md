# 3D brain asset

- **File:** `brain.glb` (~2.5 MB, glTF 2.0)
- **Source:** [thebuggeddev/anatomy](https://github.com/thebuggeddev/anatomy)
- **Contents:** albedo + normal + metallic/roughness textures (detailed cortex)
- **Runtime:** `BrainScene.tsx` keeps those maps and adds studio lighting for an illustrative look

Do not replace materials with a flat color — that removes the detailed texture.
